# 🌐 Бесплатная подписка VPN | Бесплатные конфиги V2Ray | Обход блокировок

**Бесплатная подписка VPN** — бесплатная ссылка-подписка V2Ray / Xray с серверами VLESS, VMess, Trojan, Shadowsocks и Hysteria2.
Работает в [Hiddify](https://github.com/hiddify/hiddify-app), v2rayNG, v2rayN, Nekobox, Streisand, FoXray.
**Без покупки VPN**, без регистрации, полностью бесплатно.

## 🔗 Ссылка на бесплатную подписку VPN

Скопируйте ссылку и добавьте её в приложение:

```
https://raw.githubusercontent.com/DrvpnTM/vpn/HEAD/sub.txt
```

Base64:

```
https://raw.githubusercontent.com/DrvpnTM/vpn/HEAD/sub_base64.txt
```

## ✨ Преимущества

- ✅ **100% бесплатно** — без покупки и регистрации
- 🔄 **Автообновление каждые 60 минут** — нерабочие серверы удаляются, новые добавляются
- 🧪 **Проверка соединения** — в список попадают только доступные серверы
- 🌍 Серверы в разных странах: VLESS Reality, VMess, Trojan, Shadowsocks, Hysteria2

## 📱 Как пользоваться

**Hiddify (Android, iOS, Windows, macOS, Linux)**
1. Скопируйте ссылку-подписку.
2. Нажмите **＋ (New Profile)** → **Add from clipboard**.
3. Выберите **Auto (Lowest ping)** и подключитесь.

**v2rayNG (Android)**: ☰ → Subscription group setting → ＋ → вставьте ссылку → Update subscription.

**Streisand / FoXray (iPhone)**: ＋ → Subscription → вставьте ссылку.

## ❓ Частые вопросы

**Эта подписка VPN действительно бесплатная?**
Да. Все серверы бесплатные, покупать VPN не нужно.

**Нужно ли купить VPN, чтобы получить подписку?**
Нет. Просто добавьте ссылку в приложение. Если нужен стабильный личный сервер, лучше купить платную подписку у надёжного провайдера.

**Как часто обновляется список?**
Каждые 60 минут. Нажмите **Update subscription** в приложении.

**Не подключается, что делать?**
Обновите подписку и выберите сервер с наименьшим пингом; бесплатные серверы могут перестать работать в любой момент.

## ⚠️ Внимание

Серверы публичные и предоставлены анонимными третьими лицами. Не используйте их для банковских операций и входа в важные аккаунты.
