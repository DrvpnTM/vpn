# 🌐 اشتراک رایگان وی پی ان | فیلترشکن رایگان و کانفیگ V2Ray رایگان

**اشتراک رایگان فیلترشکن** برای ایران و همه کشورها — لینک ساب (Subscription) رایگان V2Ray / Xray با پروتکل‌های
VLESS، VMess، Trojan، Shadowsocks و Hysteria2؛ مناسب برای
[Hiddify](https://github.com/hiddify/hiddify-app)، v2rayNG، v2rayN، Nekobox، Streisand و FoXray.
بدون نیاز به **خرید فیلترشکن**، بدون ثبت‌نام و کاملاً رایگان.

> 📱 **پیشنهاد ما برای اندروید: [Dr VPN (دکتر وی پی ان)](https://github.com/DrvpnTM/app/releases/latest)** — برنامه رایگان و متن‌باز با اتصال یک‌لمسی، تست خودکار سرورها، انتخاب سریع‌ترین سرور و حالت مخصوص نت ملی. این لینک اشتراک را در آن هم می‌توانید استفاده کنید.

## 🔗 لینک اشتراک رایگان وی پی ان

لینک زیر را کپی کنید و در برنامه فیلترشکن خود اضافه کنید:

```
https://raw.githubusercontent.com/DrvpnTM/vpn/HEAD/sub.txt
```

Base64:

```
https://raw.githubusercontent.com/DrvpnTM/vpn/HEAD/sub_base64.txt
```

## ✨ ویژگی‌ها

- ✅ **۱۰۰٪ رایگان** — بدون خرید، بدون ثبت‌نام، بدون محدودیت حجم از طرف ما
- 🔄 **به‌روزرسانی خودکار هر ۶۰ دقیقه (هر ساعت)** — کانفیگ‌های خراب حذف و کانفیگ جدید اضافه می‌شود
- 🧪 **تست اتصال** — فقط سرورهایی که در دسترس هستند در لیست قرار می‌گیرند
- 🌍 سرور از کشورهای مختلف با پروتکل‌های VLESS Reality، VMess، Trojan، Shadowsocks، Hysteria2

## 📱 آموزش استفاده از اشتراک رایگان

**هیدیفای (Hiddify) — اندروید، iOS، ویندوز، مک، لینوکس**
1. لینک اشتراک بالا را کپی کنید.
2. در Hiddify روی **＋ (New Profile)** و سپس **Add from clipboard** بزنید.
3. حالت **Auto (Lowest ping)** را انتخاب کنید و وصل شوید.

**v2rayNG (اندروید)**: منوی ☰ ← Subscription group setting ← ＋ ← لینک را وارد کنید ← Update subscription.

**Streisand / FoXray (آیفون)**: ＋ ← Subscription ← لینک را وارد کنید.

## 📥 اشتراک رایگان جداگانه برای هر پروتکل

اگر فقط یک نوع پروتکل می‌خواهید، لینک همان پروتکل را اضافه کنید. همه این لینک‌ها مخصوص drvpn.net هستند و هر ۶۰ دقیقه به‌روز می‌شوند.

| پروتکل | لینک اشتراک |
|---|---|
| VLESS | `https://raw.githubusercontent.com/DrvpnTM/vpn/HEAD/subs/vless.txt` |
| VMess | `https://raw.githubusercontent.com/DrvpnTM/vpn/HEAD/subs/vmess.txt` |
| Trojan | `https://raw.githubusercontent.com/DrvpnTM/vpn/HEAD/subs/trojan.txt` |
| Shadowsocks | `https://raw.githubusercontent.com/DrvpnTM/vpn/HEAD/subs/ss.txt` |
| Hysteria2 | `https://raw.githubusercontent.com/DrvpnTM/vpn/HEAD/subs/hysteria2.txt` |
| Cloudflare (CDN) | `https://raw.githubusercontent.com/DrvpnTM/vpn/HEAD/subs/cloudflare.txt` |
| WARP (Hiddify) | `https://raw.githubusercontent.com/DrvpnTM/vpn/HEAD/subs/warp.txt` |

کانفیگ‌های Cloudflare از طریق CDN کلودفلر وصل می‌شوند و هر کاربر به نزدیک‌ترین دیتاسنتر کلودفلر در کشور خود (مثلاً قاهره برای مصر) متصل می‌شود.

لینک WARP فقط در برنامه Hiddify کار می‌کند. آی‌پی خروجی WARP مربوط به نزدیک‌ترین دیتاسنتر کلودفلر به کاربر است؛ مثلاً کاربران داخل مصر آی‌پی مصر می‌گیرند.

## 🤖 برای ربات‌ها، خزنده‌ها و ابزارهای کانفیگ‌یاب

همه لینک‌ها در یک فایل JSON ماشین‌خوان هستند. ربات‌های تلگرام، اسکریپت‌ها و ابزارهای کانفیگ‌یاب می‌توانند مستقیم از آن استفاده کنند (بدون نیاز به کلید API، هر ۶۰ دقیقه به‌روز می‌شود):

```
https://raw.githubusercontent.com/DrvpnTM/vpn/HEAD/subscriptions.json
```

```bash
curl -s https://raw.githubusercontent.com/DrvpnTM/vpn/HEAD/subscriptions.json
```

## ❓ سوالات متداول

**آیا این اشتراک وی پی ان واقعاً رایگان است؟**
بله. همه کانفیگ‌ها رایگان هستند و نیازی به خرید فیلترشکن یا پرداخت هزینه نیست.

**آیا برای دریافت اشتراک باید فیلترشکن بخرم؟**
خیر. کافی است لینک اشتراک را در برنامه وارد کنید. اگر به سرور اختصاصی و پایدار نیاز دارید، خرید اشتراک پولی از یک فروشنده معتبر گزینه بهتری است.

**کانفیگ‌ها چند وقت یک‌بار به‌روز می‌شوند؟**
هر ۶۰ دقیقه (هر ساعت). در برنامه خود دکمه **Update subscription** را بزنید.

**کانفیگ وصل نمی‌شود، چه کنم؟**
اشتراک را به‌روز کنید و از حالت «کمترین پینگ» استفاده کنید؛ کانفیگ‌های رایگان ممکن است زود از کار بیفتند.

## ⚠️ توجه

این کانفیگ‌ها عمومی هستند و توسط افراد ناشناس ارائه می‌شوند. برای کارهای حساس (بانکی، ورود به حساب‌های مهم) از آن‌ها استفاده نکنید.
