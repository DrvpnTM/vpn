# 🌐 اشتراک رایگان وی پی ان

<div dir="rtl">

لینک‌های **اشتراک رایگان وی پی ان** (V2Ray / Xray) برای استفاده در
[Hiddify](https://github.com/hiddify/hiddify-app)، v2rayNG، Nekobox، Streisand و سایر کلاینت‌ها.

کانفیگ‌ها از منابع عمومی جمع‌آوری، تکراری‌ها حذف و اتصال سرورها تست می‌شود.
فایل‌ها هر ۶ ساعت به‌صورت خودکار به‌روز می‌شوند.

## 📱 نحوه استفاده در Hiddify

1. لینک اشتراک بالا را کپی کنید.
2. در برنامه Hiddify روی **＋ (New Profile)** بزنید.
3. گزینه **Add from clipboard** را انتخاب کنید.
4. روی دکمه اتصال بزنید؛ برای یافتن سریع‌ترین سرور از **Auto (Lowest ping)** استفاده کنید.

## 🛠 به‌روزرسانی دستی

```bash
python3 scripts/update.py
```

برای کارهای حساس (بانکی، ورود به حساب‌های مهم) از آن‌ها استفاده نکنید.
