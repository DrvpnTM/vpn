# 🌐 اشتراك VPN مجاني | كونفيج V2Ray مجاني | كسر الحجب مجاناً

**اشتراك VPN مجاني** — رابط اشتراك V2Ray / Xray مجاني بخوادم VLESS و VMess و Trojan و Shadowsocks و Hysteria2.
يعمل مع [Hiddify](https://github.com/hiddify/hiddify-app) و v2rayNG و v2rayN و Nekobox و Streisand و FoXray.
**بدون شراء VPN**، بدون تسجيل، ومجاني بالكامل.

## 🔗 رابط اشتراك VPN المجاني

انسخ الرابط التالي وأضفه إلى تطبيقك:

```
https://raw.githubusercontent.com/DrvpnTM/vpn/HEAD/sub.txt
```

Base64:

```
https://raw.githubusercontent.com/DrvpnTM/vpn/HEAD/sub_base64.txt
```

## ✨ المميزات

- ✅ **مجاني 100٪** — بدون شراء أو تسجيل
- 🔄 **تحديث تلقائي كل 60 دقيقة** — حذف الخوادم المعطلة وإضافة خوادم جديدة
- 🧪 **اختبار الاتصال** — نضيف فقط الخوادم المتاحة
- 🌍 خوادم من دول متعددة: VLESS Reality و VMess و Trojan و Shadowsocks و Hysteria2

## 📱 طريقة الاستخدام

**Hiddify (أندرويد، iOS، ويندوز، ماك، لينكس)**
1. انسخ رابط الاشتراك أعلاه.
2. اضغط **＋ (New Profile)** ثم **Add from clipboard**.
3. اختر **Auto (Lowest ping)** واتصل.

**v2rayNG (أندرويد)**: ☰ ← Subscription group setting ← ＋ ← الصق الرابط ← Update subscription.

**Streisand / FoXray (آيفون)**: ＋ ← Subscription ← الصق الرابط.

إذا كنت تريد بروتوكولاً واحداً فقط، أضف رابطه. جميع الروابط من drvpn.net وتُحدَّث كل 60 دقيقة.

| 🇪🇬 Egypt IP — direct, no WARP | `https://raw.githubusercontent.com/DrvpnTM/vpn/HEAD/subs/egypt_direct.txt` |

كونفيجات Cloudflare تتصل عبر شبكة CDN الخاصة بكلاودفلير، ويتصل كل مستخدم بأقرب مركز بيانات لكلاودفلير في بلده (مثل القاهرة لمستخدمي مصر).

رابط WARP يعمل فقط في تطبيق Hiddify. عنوان IP الخارجي لـ WARP يعتمد على أقرب مركز بيانات لكلاودفلير للمستخدم؛ فمثلاً المستخدمون داخل مصر يحصلون على IP مصري.

رابط 🇪🇬 مصر (Hiddify فقط): بروكسيات مصرية عامة تتصل بها عبر WARP؛ كل ساعة نُبقي فقط البروكسيات التي تعطي فعلاً IP مصرياً. هذه بروكسيات عامة؛ لا تستخدمها للعمليات الحساسة.

## ❓ الأسئلة الشائعة

**هل اشتراك VPN هذا مجاني حقاً؟**
نعم، جميع الخوادم مجانية ولا حاجة لشراء VPN.

**هل يجب أن أشتري VPN للحصول على الاشتراك؟**
لا. فقط أضف رابط الاشتراك إلى التطبيق. إذا كنت تحتاج إلى خادم خاص ومستقر، فشراء اشتراك مدفوع من مزود موثوق خيار أفضل.

**كم مرة يتم التحديث؟**
كل 60 دقيقة. اضغط **Update subscription** في التطبيق.

**الخادم لا يتصل، ماذا أفعل؟**
حدّث الاشتراك واختر الخادم الأقل تأخيراً؛ الخوادم المجانية قد تتوقف في أي وقت.

## ⚠️ تنبيه

هذه الخوادم عامة ويقدمها أشخاص مجهولون. لا تستخدمها للعمليات الحساسة مثل الخدمات المصرفية.
