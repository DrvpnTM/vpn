# 🌐 Langganan VPN Percuma | Config V2Ray Percuma | VPN Free

**Langganan VPN percuma** — pautan langganan V2Ray / Xray percuma dengan pelayan VLESS, VMess, Trojan, Shadowsocks dan Hysteria2.
Berfungsi dengan [Hiddify](https://github.com/hiddify/hiddify-app), v2rayNG, v2rayN, Nekobox, Streisand dan FoXray.
**Tidak perlu beli VPN**, tanpa pendaftaran, percuma sepenuhnya.

- ✅ **100% percuma** — tiada pembelian atau pendaftaran
- 🔄 **Kemas kini automatik setiap 6 jam** — pelayan rosak dibuang, pelayan baharu ditambah
- 🧪 **Ujian sambungan** — hanya pelayan yang boleh dicapai disenaraikan
- 🌍 Pelayan dari pelbagai negara: VLESS Reality, VMess, Trojan, Shadowsocks, Hysteria2

## 📱 Cara menggunakan

**Hiddify (Android, iOS, Windows, macOS, Linux)**
1. Salin pautan langganan di atas.
2. Tekan **＋ (New Profile)** → **Add from clipboard**.
3. Pilih **Auto (Lowest ping)** dan sambung.

**v2rayNG (Android)**: ☰ → Subscription group setting → ＋ → tampal pautan → Update subscription.

**Streisand / FoXray (iPhone)**: ＋ → Subscription → tampal pautan.

## ❓ Soalan lazim

**Adakah langganan VPN ini benar-benar percuma?**
Ya. Semua pelayan percuma; anda tidak perlu membeli VPN.

**Perlukah saya beli VPN untuk mendapatkan langganan?**
Tidak. Hanya tambah pautan ke aplikasi. Jika anda perlukan pelayan peribadi yang stabil, membeli langganan berbayar daripada penyedia yang dipercayai adalah pilihan lebih baik.

**Berapa kerap dikemas kini?**
Setiap 6 jam. Tekan **Update subscription** dalam aplikasi.

**Tidak dapat sambung, apa perlu buat?**
Kemas kini langganan dan pilih pelayan dengan ping terendah; pelayan percuma boleh berhenti berfungsi bila-bila masa.
